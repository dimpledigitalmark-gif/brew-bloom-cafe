# Brew & Bloom Cafe — Demo Website

A responsive cafe website demo built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation, menu filtering, footer year

## Run locally
Open `index.html` in a browser. An internet connection is needed for Google Fonts and remote Unsplash photos.

## Customize before sharing
1. Replace "Brew & Bloom" with the real cafe name.
2. Replace demo menu items/prices, address, opening hours and story.
3. Replace the WhatsApp link with the cafe's actual number in international format, digits only. Example for India: `https://wa.me/91XXXXXXXXXX`.
4. Replace photos with cafe-owned/licensed photos where possible.
5. Test every link and layout on mobile and desktop.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository, e.g. `cafe-demo`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the published URL shown in the Pages section and open it to test.

Note: This is a portfolio/demo concept. Sample prices, location, opening hours, and cafe information are placeholders, not claims about a real business.
